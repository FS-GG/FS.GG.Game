# FS.GG.Game architecture decisions

Decisions that stay inside FS.GG.Game. A decision that sets a boundary between repositories belongs in an organization
ADR in [FS-GG/.github `docs/adr`](https://github.com/FS-GG/.github/tree/main/docs/adr); a record here executes such a
decision and cites it. Numbers are local to this directory. Cite them as "FS.GG.Game ADR 0001" so they are not confused
with the organization's ADR-0001.
